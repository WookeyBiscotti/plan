# План команды

Доска, на которой входящая крупная оценка становится датой в текущем плане.

## Как пользоваться

1. Слева — бэклог с грубыми оценками в рабочих днях.
2. Перетащите задачу на дорожку исполнителя — полоса займёт ближайшие свободные дни, начиная с выбранной даты. Выходные пропускаются.
3. В правой панели разбейте работу на подзадачи и раздайте людям.
4. Укажите зависимости («ждёт» или режим «Связать»). Независимые куски на разных людях идут параллельно, поэтому срок эпика — это критический путь, а не сумма частей.

Демо уже содержит эпик «Платежный шлюз»: исследование, затем параллельно API и UI, затем склейка.

Данные хранятся в `localStorage` браузера. Кнопка «Сбросить демо» возвращает стартовый пример.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build
```

Артефакты — в папке `dist/`.

## GitHub Pages

При push в `master` или `main` workflow [deploy-gh-pages.yml](.github/workflows/deploy-gh-pages.yml) собирает статический сайт и публикует его в ветку `gh-pages`.

В **Settings → Pages → Build and deployment** укажите источник **Deploy from a branch**, ветка **`gh-pages`**, папка **`/ (root)`**.

Сайт: https://wookeybiscotti.github.io/plan/
